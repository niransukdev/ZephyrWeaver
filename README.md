# ZephyrWeaver

A simple ZephyrWeaver framework for real time data processing.

ZephyrWeaver is aimed at developers who need a straightforward, dependable solution.

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ZephyrWeaver.git`
2. `cd ZephyrWeaver`
3. Install in editable mode: `pip install -e .`

## Configuration

ZephyrWeaver is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
